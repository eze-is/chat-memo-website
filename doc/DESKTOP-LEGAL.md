# 桌面版法律文档

公开正文适用于Chat Memo桌面版及相关账号、连接和AI互通服务，由本仓维护。原官网与插件政策入口保持原状。2026-11-04用户已指定中英文两份文档正式发布，首个正式版本为`2026-11-04.1`，当前隐私政策为`2026-11-04.3`、用户协议为`2026-11-05.1`，移除Draft、单列生效日期和开头的审阅／尚未生效说明。网页发布不等于系统已记录每位用户的同意。

## 中英文地址与语言选择

- `/en/desktop/privacy`、`/en/desktop/terms`：英文静态正文。
- `/zh-CN/desktop/privacy`、`/zh-CN/desktop/terms`：中文静态正文。
- 原`/desktop/privacy`、`/desktop/terms`：英文静态兜底，启用脚本时按官网规则导航到对应语言；原App链接继续有效。

语言路径、`?lang=`、官网已保存的语言选择、浏览器语言依次决定语言。法律文档只提供中英两种；其他语言选择回退英文。页面右上角使用官网语言图标及中英文下拉菜单，开合、Escape、外部点击和焦点管理复用`site-nav.js`；手动选择通过`site-i18n.js`保存同一官网偏好，并保留文档、其他查询参数及章节片段。法律页不读取营销词包、不用客户端替换正文。旧地址无脚本时展示英文，不假装按设备语言生成首响应。

各语言页面有自指canonical、中英文互返hreflang与指向中立入口的x-default。正式页面采用index,follow，sitemap仍由现有营销页生成器维护，不生成未翻译的日文或西班牙文法律页。英文是中文的翻译，没有新增英文优先、英国适用法或其他地区条款。

页面沿用官网品牌、白底、灰黑文字、蓝色链接及字体栈，显示品牌、语言切换、标题、版本与正文。2026-11-04按用户新增要求，底部提供定价、用户协议与隐私政策入口，隐私政策仅指向桌面版政策，不再展示插件旧政策入口；沿用官网词包与路由，法律正文和正式版本不变。不设下载、固定版本入口、法律目录页或章节导航。

## 正文与生成

`desktop/legal/versions/{zh-CN,en}/`分别保存已确认中文及经独立审阅的英文。`scripts/build-desktop-legal.mjs`选择版本并校验各语言SHA256，生成四个语言页面和两个中立入口；路由复用官网`site-i18n.js`，不用另一套语言检测或偏好。源版本用于内部追溯，不提供版本浏览功能。当前两份正式源均置于`2026-11-07.1-published/`，保留此前Draft及正式源不覆盖；首个公开正式版本按用户要求为`2026-11-04.1`，两种源由各自路径与SHA256区分。后续已正式发布正文修订须增加公开版本号及源快照。

Desktop仓Markdown仅为原讨论冻结记录，App不再读取。App沿既有Main安全导航打开网站，官网发布不等于安装包已更新，不把阅读或语言切换记录为法律接受。

```sh

```
