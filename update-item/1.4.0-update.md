标题：Chat Memo v1.4.0：保存与数据安全全面改进

内容：

更稳定地保存 AI 对话，更安心地保留你的数据。全量修复 GPT、豆包等平台的保存问题。若更新后旧会话无法自动记录，请在 Chat Memo 中删除对应会话后重试即可。

——————
🚀 本次更新亮点：

1️⃣ 保存机制大修复
修复豆包、ChatGPT 等平台的同步问题。过往出错、无法保存或无法继续同步的旧会话，可在 Chat Memo 中删除对应记录后重新采集。

2️⃣ 网页删除不再同步
为提升同步稳定性，网页内手动删除的消息不再同步删除。

3️⃣ 统一自动保存
手动保存模式已下线，仍可在设置中暂停自动保存。

4️⃣ 数据备份与升级须知
本次升级涉及数据迁移，Chat Memo 会在迁移前自动保留本地数据快照。从 1.3.3 升级后，你可在设置 → 数据备份中随时下载升级前的数据快照，同时获取 Markdown 文档。

——————
📥 如何更新？

1️⃣ 如果你已经在使用 Chat Memo，插件会自动更新到最新版本。也可以手动在浏览器的扩展管理页面中更新
