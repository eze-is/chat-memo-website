v1.5.0

Adds Japanese and Spanish interfaces and per-platform auto-save controls, with better narrow-sidebar layouts and conversation saving.

September 25, 2026
🚀

New Features

Japanese and Spanish interfaces

When Chrome's interface language is Japanese or Spanish, Chat Memo displays its interface in that language. Saved conversation text stays unchanged; unsupported interface languages fall back to English.

Per-platform auto-save controls

Pause or enable auto-save for each of the nine platforms in Platform settings. Turning off the main switch pauses all platforms while preserving their individual choices; the floating capsule still shows the paused state.

✨

Improvements

Clearer current-conversation status

The library marks the record matching the current page and shows when auto-save is paused. If multiple local records match a conversation, you can review them; existing copies are not automatically merged or deleted.

Better narrow-sidebar layout and mixed-language reading

Search, multi-select, export, and date filters adapt to narrower sidebars, while titles and content with mixed scripts render more consistently.

🔧

Bug Fixes

Improve Google AI Mode saving

Matches local records by conversation content to reduce duplicates caused by changing source links. Distinct content branches are saved separately while the original record remains.

Fix save targeting when switching Gemini conversations

Fixes a case where switching Gemini conversations in the same tab could write content from the previous conversation into the new record.

New Features

Data backups and upgrade notes

This upgrade includes a data migration. Chat Memo automatically retains a local snapshot before migration. After upgrading from 1.3.3, you can download your pre-upgrade data snapshot and Markdown documents from Settings → Data Backup.

✨

Improvements

Major saving fixes

Fixed syncing issues on Doubao, ChatGPT, and other platforms. If an existing conversation previously failed to save or no longer syncs, delete its record in Chat Memo and capture it again.

Website deletions no longer sync

To improve sync stability, manually deleting messages on a website no longer deletes them in Chat Memo.

Auto-save for all capture

Manual saving has been removed. You can still pause auto-save in Settings.
