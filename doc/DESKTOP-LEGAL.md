# 桌面版法律文档

公开正文适用于Chat Memo桌面版及相关账号、连接和AI互通服务，由本仓维护。原官网与插件政策入口保持原状。当前仍是未生效审阅稿，阅读页面不表示接受条款或新的数据处理授权，Draft不推迟实际数据处理义务。

## 中英文地址与语言选择

- `/en/desktop/privacy`、`/en/desktop/terms`：英文静态正文。
- `/zh-CN/desktop/privacy`、`/zh-CN/desktop/terms`：中文静态正文。
- 原`/desktop/privacy`、`/desktop/terms`：英文静态兜底，启用脚本时按官网规则导航到对应语言；原App链接继续有效。

语言路径、`?lang=`、官网已保存的语言选择、浏览器语言依次决定语言。法律文档只提供中英两种；其他语言选择回退英文。页面提供简洁的“简体中文／English”真实链接，禁用脚本仍可切换；手动选择通过`site-i18n.js`保存同一官网偏好，并保留文档、其他查询参数及章节片段。法律页不读取营销词包、不用客户端替换正文。旧地址无脚本时展示英文，不假装按设备语言生成首响应。

各语言页面有自指canonical、中英文互返hreflang与指向中立入口的x-default。审阅稿保持noindex，不加入正式sitemap，不生成未翻译的日文或西班牙文法律页。英文是中文的翻译，没有新增英文优先、英国适用法或其他地区条款。

页面沿用官网品牌、白底、灰黑文字、蓝色链接及字体栈，只显示品牌、语言切换、标题、版本／生效日期与正文。不设下载、固定版本入口、法律目录页或章节导航。

## 正文与生成

`desktop/legal/versions/{zh-CN,en}/`分别保存已确认中文及经独立审阅的英文。`scripts/build-desktop-legal.mjs`选择版本并校验各语言SHA256，生成四个语言页面和两个中立入口；路由复用官网`site-i18n.js`，不用另一套语言检测或偏好。源版本用于内部追溯，不提供版本浏览功能。发布后修改正文时新增源版本，不覆盖旧原文。

Desktop仓Markdown仅为原讨论冻结记录，App不再读取。App沿既有Main安全导航打开网站，官网发布不等于安装包已更新，不把阅读或语言切换记录为法律接受。

```sh
npm run build:legal
npm run check:legal
npm test
npm run check:i18n
```

## 2026-11-04修订与独立翻译审阅

中文两份当前版本均为`2026-11-04.1`。用户已要求从条款第三节删除年卡一年使用权、不自动续费及到期本机资料说明，从隐私政策删除“目前不提供整库云同步”。英文以该最新中文为基准，不恢复这些已删内容。商业期限、续费等由购买前页面和交易说明承载，文案调整不改变当前商品实现。

未参与此次翻译的独立审阅者逐段核对准确性、完整性与国际英文软件产品的自然表达。初审发现并修正：赔偿上限必须明确限于付费服务；更新部分“未履行权益”应表达为我们尚未提供的权益，不能混同用户尚未使用。另调整产品用途句与撤销连接后的副本措辞。主体保留已确认中文名称，不虚构官方英文登记名。修订后的译文与双语实现已由同一独立审阅者复审通过，未发现必须修复的问题。该审阅不属于执业律师法律意见。

## 验证与发布

正文完整性、双语互链及元信息、语言优先级、英文回退、官网偏好、同文档切换、禁用词包加载、两语版本保护测试，以及原官网四语检查共同验收。原文静态可读，只有语言导航依赖共享脚本；官网基础设施可能另外注入既有边缘统计，不能以本片无新增统计脚本推断基础设施完全不处理访问数据。

官网沿现有Cloudflare Pages从main根目录发布，全部生成HTML随源提交。独立复审、最终浏览器切换／宽窄屏及生产地址结果在发布前后分别核对。接受凭证、注销清理、正式生效及安装包继续按各自负责模块验收，不由本次翻译发布替代。

本地验收：25项测试、六页生成一致性与原官网四语产物检查通过。隔离Chrome已检查中英两份文档在1440／390宽度的8张截图，均已查看；320窄屏无横向溢出。真实键盘切换、共享官网偏好、中立入口导航、明确语言路径优先、日／西语回退英文、中文浏览器选择以及无脚本正文与语言链接通过。证据位于兄弟Desktop仓的忽略目录`test-results/legal-i18n/`；这是本地浏览器证据，生产结果须另行读回。
