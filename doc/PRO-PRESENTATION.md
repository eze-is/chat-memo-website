# Desktop Pro 公共展示配置归属

统一公共文档由 API 仓 `services/api/public-config/pro-presentation.v1.json` 拥有，通过现有 Static Assets 的 `/public-config/pro-presentation.v1.json` 发布。API 内的 `services/api/docs/PUBLIC-PRO-CATALOG.md` 拥有契约、地区响应头与验收边界。

官网不保留价格、销售文案或套餐对比的第二份配置，也不为此配置独立缓存规则。原 Pages 候选路径未公开发布，已在本轮退役。Desktop 的包内快照随发行冻结，不因运营更新自动改写。


## 官网定价页（2026-11-04）

`pricing.html`及四语`/{locale}/pricing`公开展示免费／Pro权益、按访问地区选择的价格、计费方式、有效期与退款说明，访问不需登录。免费／Pro清单和交易说明静态可读，适用价格由浏览器确认网络地区后显示。沿用官网导航、页脚与语言菜单，不接入支付、不读取访客账号，也不请求设备定位权限。

`npm run build:i18n`及`check:i18n`在写入输出前，从生产`https://api.chatmemo.ai/public-config/pro-presentation.v1.json`读取并验证当前已发布目录。金额、商品期限及可用功能由`scripts/pro-pricing.mjs`派生；目录不可用、未知商品／期限或缺少功能译文会阻止生成，不猜价格、不回退源码未发布配置。计划功能不作为已交付权益展示。HTML记录`data-catalog-version`，不保留另一份价格配置。功能名称和固定交易文案由四语词包拥有。

价格变更时，先由API按原发布合同完成生产部署，再运行官网生成、检查并发布网站；`check:i18n`会发现官网静态展示与当前生产目录的差异。网站访客不额外请求销售API；地区请求及失败语义见下节。套餐含计划状态或新feature ID时须人工审阅，而不是将新功能自动当作已承诺交付。

购买入口与收费启用仍由产品和支付模块拥有。当前支付尚未开放，官网如实说明，不创建订单、假支付按钮或自动授予权益。用户于2026-11-04进一步确认：退款能力尚未接通，当前公开文案改为“目前暂不支持退款，法律另有规定的除外”，替代前次列举具体退款例外的表述。联系邮箱保持eze@chatmemo.ai，不额外承诺7天或14天自愿退款。不把现有权益撤销实现等同资金退款。


## 地区报价与付款页风格（2026-11-04）

按用户后续要求，公开页只显示一档报价，不同时展示人民币和美元；人民币文案为“早鸟价 CNY 99／年”（以生产目录实际金额为准），不出现“中国大陆”标签。`pricing-region.js`只消费本站Cloudflare现有`/cdn-cgi/trace`的`loc`：CN选cn，其余有效国家选global，不按界面语言猜测。国家表示访问网络出口，不宣称居住地。地区仅决定展示，不赋予账号、订单或购买资格。

两档价及已交付权益依旧由生产目录生成，初始价格节点均隐藏；脚本取得地区后只显示一档，避免先闪现另一币种。地区缺失、非法、请求失败或超时均明确提示无法读取价格，用户可重试；不显示猜测价、不默认特价，不轮询、不落盘缓存、不保存或记录trace／IP。价格展示需要脚本；无脚本仍能阅读权益及交易说明，并提示启用JavaScript。此范围取代上节旧版双价全静态展示。Cloudflare端点说明：https://developers.cloudflare.com/fundamentals/reference/cdn-cgi-endpoint/ 。

页面沿用实际付款页的MiSans、品牌色、轻玻璃轮廓与24px圆角，按产品内PlanComparison的免费／Pro卡片列已交付权益，删除原整张表格和移动端逐行Free/Pro重复标签。计划功能仍不列入已交付权益。正文、导航、语言菜单、页脚及退款规则保持；未创建付款按钮或开启收款。字体子集与许可证、重生成入口见`resource/fonts/README.md`。
