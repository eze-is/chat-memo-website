可以，只要手动点开对应聊天记录，就可以触发保存（Gemini 由于特殊加载机制，超过 20 条消息的对话，需要手动加载历史消息）

Chat Memo 目前支持 ChatGPT、Gemini、Claude、DeepSeek、Google AI Mode、豆包、Kimi、通义千问和腾讯元宝的网页端对话。
手机 App、桌面客户端及 Coding 工具内的对话暂不支持自动保存。
如有需求，欢迎通过 反馈 告诉我们。

可能是网页和插件之间初始化失败，重新刷新一次网页即可。如还有问题，请通过 Feedback 联系作者排查。

如果所在浏览器无法打开侧边栏，建议先在最新版 Chrome 或 Edge 中尝试。若仍有问题，请附上浏览器名称和版本反馈给我们，以便排查。

感谢反馈。为了醒目地提醒保存状态，当时悬浮标签是刻意做得明显。目前介意的话，可以随意拖动悬浮标签的位置，放到你想放的地方～

如果是 Chat Memo 已支持的平台，请先在 Chat Memo 中删除这条对话记录，再刷新原网页，重新抓取。
抓取历史消息时，请匀速、稳定地滚动，等每批内容加载完成后再继续，避免快速滚动、连续触发页面加载。
如果仍然抓取不完整，请通过 Feedback 联系作者排查。

Chat Memo 目前会同步对话中的新增消息，以及已有消息的明确变更。
对于直接删除已有消息的行为，受网页内容加载与识别机制限制，Chat Memo 暂时不会主动同步删除，以免误删已经保存的内容。
如果希望两边完全一致，可以在 Chat Memo 中删除整条对话记录，再从原网页重新抓取。单条消息删除功能将在后续版本中支持。
