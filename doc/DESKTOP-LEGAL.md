# 桌面版法律文档的发布与维护

## 本轮标准与范围

用户授权将已讨论的中文版放在chatmemo.ai，路径由实现者确定，并采用App点击后由系统浏览器阅读的方式。本轮提供公开的**未生效审阅稿**，不把上传网页解释成正式法律接受或实际处理合规已完成。

- `/desktop/privacy`：桌面版隐私政策。
- `/desktop/terms`：桌面版用户协议。
- `/desktop/legal/`：范围、状态及固定版本入口。
- `/desktop/legal/versions/zh-CN/<版本>/<文档>`：固定版本阅读页，同目录`.md`为原文。

使用小写、HTTPS、产品范围明确的地址，保留既有插件官网与旧隐私链接。路径不绑定具体安装包版本；网页以固定法律文档版本归档。当前只有经过用户讨论的中文稿，`lang=zh-CN`且显著标明审阅状态，不冒充已提供其他语言或正式生效文本。

功能与验收：全部正文静态输出、不依赖JavaScript或外部字体／统计脚本；页面正文与版本原文一致，固定链接可直接打开；390／768／1440宽度可阅读、无横向溢出，目录锚点及键盘链接可用；原官网四语页面与插件隐私链接不变。App沿既有Main安全导航交给系统浏览器，不新增Electron远程窗口，不以点击链接记录同意。

法律文档按用户要求采用普通阅读页。保留品牌和已确认法律编号，不引入营销图片、动效、宣传段落或新的交互实体；这些内容优先于设计Skill面向营销页的图片及动效要求。视觉检查仍用独立无头Chrome/CDP，不使用Playwright或用户日常浏览器资料。

## 单一正文来源

公开发布版本的正文由本仓`desktop/legal/versions/zh-CN/`拥有。`scripts/build-desktop-legal.mjs`明确当前版本及其SHA256，从该原文生成当前入口与固定版本HTML。已发布原文不修改；修订时新增版本文件、更新脚本指针及哈希，再生成新页面，保留旧版本。

Desktop仓原有Markdown是本次讨论稿的冻结记录，App不再读取它们；以后不在两个仓各自手改一份“最新版”。需要改文案时在本仓新增版本并完成相应审查。官网公开版本的发布不等于安装包已更新，也不等于接受／通知功能已实现。

生成与检查：

```sh
npm run build:legal
npm run check:legal
npm test
npm run check:i18n
```

当前审阅稿不进入正式收录清单，页面使用`noindex, follow`。正式启用、语言和接受机制完成后，再按实际发布状态调整收录信息；不在本轮改造整站SEO或产品首页。

## 发布边界

官网由现有Cloudflare Pages从`main`根目录发布，无额外构建命令；生成的HTML与CSS须随本片提交。仅发布本片文件，不把Desktop或其他在途工作一并推送。网站发布后验证正式域名、固定版本、原文、样式和原有首页的响应；接受记录、邮件注销和数据清理仍按Desktop与账号服务各自的执行边界处理。

## 本地验证与独立复核

官网23项测试、5个生成页一致性及现有四语产物检查通过。首次运行因本机尚未安装已声明的parse5依赖失败，按锁文件安装后复跑；正文测试的一处假差异来自测试错误地在内联邮箱链接周围插入空格，改用符合块／内联语义的文本提取后通过，正文未因此改写。

独立只读审查确认网站版本MD与桌面讨论稿逐字节一致、正文静态完整、旧App弹窗和运行时MD读取已退役、原首页与插件链接未改；审查者本人复跑官网23项及Desktop入口／导航26项测试通过。作者的Desktop45项定向测试和完整类型检查也通过；不将其扩大为系统浏览器原生启动或新安装包验收。

无头Chrome/CDP已在1440、768、390宽度检查两份最终页面并查看全部截图，未发现横向溢出、缺字或隐藏正文。Inspector在明确排除营销图片、视频、动效和大幅海报标题要求后为0 FAIL；保留两个不适合直接套用的提醒：其按西文字宽估算行长，而中文实际单行约40余字；其“裸标题”规则未把18px的“Chat Memo桌面版·简体中文”当作足够说明。法律标题及产品／语言范围在实际截图中均清楚，故不增加营销副标题或图片。

该检查使用项目外的临时隔离Chrome资料及Desktop忽略目录中的截图，没有使用Playwright、私人浏览器资料或前台窗口。公开网络与部署结果另以实际发布后验证为准。
