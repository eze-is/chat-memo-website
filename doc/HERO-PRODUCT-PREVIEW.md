# Hero 产品展示预览

2026-11-05，官网发布版本。它只替换当前官网的 Hero 媒体与两颗按钮，不修改另一个在途的 `devtools/homepage-preview/` 整页方案，也不修改 Desktop 源码。

## 当前确认

- 默认展示 Chat Memo 桌面端。悬停／聚焦「安装插件」切到现有插件视频，回到下载入口切回桌面端。
- 桌面端只开放真实窗口顶部首页、记录、连接三个 Tab。未操作时自动轮换：首页 3.6 秒、记录 8.75 秒、连接 4.8 秒；用户点击某个 Tab 后固定重播该页。没有浮动解释、演示标签或按钮用途注释。
- 首页演出新消息存入和一次跨 AI 取用；记录页先停留两秒显示默认列表及 Claude 原文，列表前排穿插 ChatGPT、WorkBuddy、豆包、DeepSeek Harness。再按原节奏搜索，自动触发续聊 CTA，展示正式 ProSheet 第一层的开通前后对比约 3.35 秒，关闭后继续轮换；连接页先显示六个本机存入开关全部关闭，0.9 秒时触发正式一键开启动作，每行显示对应今日会话／消息数，停留后滚到网页来源及其今日数量。
- 活动统计、设置、Pro、付款、续聊 CTA 和其他深层动作均不开放用户点击；仅编排可触发上述能力对比，弹窗可关闭，原能力按钮在官网演示中改为「与另一个 AI 接着聊」（英文 Continue with another AI），只作展示，不进入方案／付款。该文案由演示目录投影，不修改正式 App。记录输入只承载编排，不是完整客户端。
- 14 个当前支持来源各有 3 段虚构对话。Google AI Mode 不加入；Grok bot 目前属于互通端，按用户本次选择不加入备份记录示例。摘要、活动、正文均为本地示例，不读取真实账号／资料，不发模型／云业务请求。
- 两颗入口采用 App 的材质语言：较大的玻璃下载按钮、较轻的普通插件按钮。Chrome／Edge 菜单是独立圆角浮层，支持悬停、键盘、点击和 Escape；下载仍为原链接。
- 首屏与页尾使用相同的下载／安装插件按钮、样式和菜单行为。下载按钮保留 App `glass-flow` 的玻璃、色调和光层宿主，官网按用户要求采用单片柔光从左向右流动并轻微舒展，减少动态时停用动画；页尾入口不会切换首屏媒体。页尾说明同时涵盖电脑和浏览器。

- 中文副标题按确认文案保留，正文宽度从672px调整为816px；英文、日文、西班牙文的主副标题按本地语言重新组织，标题简述保存与跨AI续聊，副标题完整说明实时保存、私密记忆和检索。外文不直译“记忆资产”。外文正文最大宽度1040px，字号保持20px；1024、1280、1440px下四语副标题均为两行。手机端自然换行，不缩小正文或截断内容。

## 呈现的唯一来源

`devtools/hero-desktop/main.tsx`直接导入当前 Desktop 的`product/v1.tsx`、`globals.css`、`product/v1.css`和`desktop-shell.css`。不复制产品 HTML 或样式，不依赖旧 UI Lab 截图。

正式装配从`../desktop/src/renderer/src/live/LibraryDesktop.tsx`核对：当前使用`recentActivityLayout="content"`、`nPill="apple-lens"`。最近活动因此为标题在上、来源与存入消息数在下；它由正式的`recent-activity.tsx`、`activity-details.tsx`与`activity-content-copy.ts`呈现。`fixture.tsx`提供相应的`turns`、时间和来源事实。后续组件或正式装配变化后，要重新构建、目视核对，不只确认组件名称。

macOS三颗原生窗控在Electron内由系统绘制；浏览器中只补回三个静态圆点。除此之外，窗口内容、字体、导航、统计、来源和阅读均由正式组件拥有。

## 构建与交付

```sh
npm run check:hero
npm run build:hero
npm run build:i18n
npm test
npm run check:i18n
```

前两步构建期显式读取兄弟 Desktop 仓及其已安装锁定依赖；字体子集工具用已有`uv`临时运行。生成结果`resource/hero-desktop/`是独立静态闭包，生产浏览器不访问 Desktop 仓或其运行时。MiSans和Geist许可随资源保留。日常仅编辑网站文字时不重建 Renderer。

`devtools/hero-desktop/poster.png`来自该 Renderer 首页静止状态截图，构建时转为逐像素和色彩配置均校验的无损 `poster.webp`，与演示图标一起按独立产物发布；改了正式首页或虚构资料后一起更新。父页`hero-preview.js`拥有切换和可见性许可，子页只拥有三页的短编排与用户选页意图。iframe 直接访问 `/resource/hero-desktop/`，避免 Pages 对 `index.html` 的额外跳转。切到插件、滚出视口、后台或减少动态时暂停；回到桌面保留用户所选页。

首页优先取桌面演示海报，iframe 入口将 MiSans 与应用脚本并行加载。插件封面在选中插件演示时加载，功能区视频接近视口时才请求封面并尝试播放，离开视口即暂停。三段 MP4 将索引放在文件开头，音视频流保持原样。

本地网页检查包括三 Tab 自动／手动、搜索速度、多来源资料、活动和付费入口拦截、菜单和两段媒体切换、隐藏／恢复／减少动态、窄屏无溢出。它不证明实机采集、真实 AI 取用、安装、付费或生产发布。当前浏览器证据与截图在该目录忽略的`evidence/`中。

本次追加动画已在构建产物上核对：六个本机开关从全部未选中变为全部选中，每行显示独立今日数量；能力对比自动关闭后可继续轮换，演示按钮不进入方案页，自动弹窗保持官网原有焦点。1440、768、390 宽度的对比弹窗截图均已检查。默认阅读项为 Claude，前五条覆盖上述五家来源，输入前留出默认列表观察时间，中英文弹窗按钮均已核对。`check:hero`为零新增源码诊断，官网当前41项测试及四语生成一致性检查通过；上线状态以 Cloudflare Pages 的 main 生产部署和正式域名核验为准。

下载按钮光效对比位于`devtools/download-effects/`，两种光效均由`node devtools/download-effects/build.mjs`从 App 实际 CSS／边缘拖尾常量导出；`build:hero`同步执行。玻璃和边缘对比仍由 App 导出，选定的官网表面流光已按用户后续要求在`hero-preview.css`中独立拥有形变编排。边缘流光沿用 App 的 6.4 秒轨迹，对比稿将 SVG 圆角适配为 56px 胶囊，并按用户反馈将拖尾加长至 2.4 倍、亮线加长为 40、线宽增至 2px 左右，以适配官网按钮尺寸。用户已选定左侧 App 表面流光，首屏及页尾统一使用；边缘方案只保留在对比稿。

按钮错位回归：用旧版仅匹配首屏 ID 的 CSS 加载新版页尾按钮，可复现底色消失、图标／文案分行。首页生成时对按钮 CSS、光效 CSS、交互脚本及语言脚本使用内容哈希，静态正文与运行时词包共享目录版本，避免旧词包覆盖新版文案。验收按正常缓存的页面导航核对两处按钮及页尾菜单。

下载按钮材质细化：白色内反射提亮玻璃，静态蓝紫光泽保持轻淡；单片白蓝柔光从左向右流动，只保留轻微伸缩和轮廓变化；移动反光按用户“太淡”的反馈增强蓝紫颜色及清晰度，静态底色保持轻淡，采用 App 的玻璃宿主。首屏与页尾共用，减少动态／透明度偏好继续生效。

流光形状修正：当前可核对的旧版`hub-share-sweep`及迁入版`v1-try-sweep`均是斜条平移，官网按用户要求改为有轻微形变的单片柔光。最终流向统一为从左向右，7.8 秒一轮，光离开后透明复位；退役两片错相、反向与交叠的编排，白蓝反射为主，保留适量紫色层次和轻淡静态底色。玻璃材质、文案、下载／菜单行为保持。验收覆盖阶段采样的横向位置单调递增、形状变化、桌面／窄屏及减少动态。

按钮多语言与切换回归：主按钮宽度随完整译文自然增长，首屏／页尾保持单行；手机占满可用宽度，极窄屏只收紧字号与内边距。营销页手动切换语言清除页内锚点，从顶部阅读；法律文档继续保留条款锚点。语言脚本在全部营销页按内容哈希加载，避免旧缓存保留原跳转行为。

官网人工下载入口统一带`?link=website`，共享导航、首屏及页尾由同一登记来源计数；四语页面随模板生成。不修改`/desktop/updates/`自动更新源，后者只接受`noCache`且排除在获客下载请求统计之外；旧App路径和发布源保持独立。

本轮发布基于最新生产分支，保留插件2.0.0更新记录与2026-11-05.1正式协议；在隔离工作区重新构建演示、生成四语页面，45项测试、词包一致性及六个法律页面检查通过。营销页统一绑定词包内容版本，避免旧缓存覆盖新的购买状态文案。完整首页实验原型不在本轮发布范围。
