# Desktop Pro 公共展示配置归属

统一公共文档由 API 仓 `services/api/public-config/pro-presentation.v1.json` 拥有，通过现有 Static Assets 的 `/public-config/pro-presentation.v1.json` 发布。API 内的 `services/api/docs/PUBLIC-PRO-CATALOG.md` 拥有契约、地区响应头与验收边界。

官网不保留价格、销售文案或套餐对比的第二份配置，也不为此配置独立缓存规则。原 Pages 候选路径未公开发布，已在本轮退役。Desktop 的包内快照随发行冻结，不因运营更新自动改写。


## 官网定价页（2026-11-04）

`pricing.html`及四语`/{locale}/pricing`公开展示免费／Pro权益、按界面语言与访问地区选择的价格、计费方式和有效期，访问不需登录。免费／Pro清单和交易说明静态可读，中文界面直接显示人民币报价；非中文界面由浏览器确认网络出口后显示适用价格。沿用官网导航、页脚与语言菜单，购买引导至桌面应用内完成；官网不接入支付、不读取访客账号，也不请求设备定位权限。

`npm run build:i18n`及`check:i18n`在写入输出前，从生产`https://api.chatmemo.ai/public-config/pro-presentation.v1.json`读取并验证当前已发布目录。金额、商品期限及可用功能由`scripts/pro-pricing.mjs`派生；目录不可用、未知商品／期限或缺少功能译文会阻止生成，不猜价格、不回退源码未发布配置。2026-11-05按用户要求，Pro清单按App同一目录顺序展示，planned项使用“计划中”标签；每行左侧为App功能图标，右侧为勾号、计划中或不可用横线。状态仍由生产目录拥有，不改变付款交付或App能力。HTML记录`data-catalog-version`，不保留另一份价格配置。套餐名称、功能文案与状态来自App共享展示资源；官网四语词包只维护页面介绍、计费说明等网页文案。

价格变更时，先由API按原发布合同完成生产部署，再运行官网生成、检查并发布网站；`check:i18n`会发现官网静态展示与当前生产目录的差异。网站访客不额外请求销售API；地区请求及失败语义见下节。套餐含计划状态或新feature ID时须人工审阅，而不是将新功能自动当作已承诺交付。

购买入口与收费启用仍由产品和支付模块拥有。用户于2026-11-05确认购买已开放，官网文案改为“请在 Chat Memo 桌面应用内查看方案并完成购买”，四语同步；官网不创建订单或自动授予权益。2026-11-04曾在定价页说明退款尚未接通；2026-11-05按用户要求，移除整个退款区块及其联系文案。本次只调整定价页展示，不修改协议条款，也不把权益撤销等同资金退款。


## 地区报价与付款页风格（2026-11-04）

按用户后续要求，公开页只显示一档报价，不同时展示人民币和美元；人民币文案为“早鸟价 CNY 99／年”（以生产目录实际金额为准），不出现“中国大陆”标签。2026-11-05按用户确认与App统一：`pricing-region.js`以页面`html.lang`为界面语言，中文界面或中国大陆出口选cn，其余有效地区的非中文界面选global。中文界面无需请求地区；其他语言只消费本站Cloudflare现有`/cdn-cgi/trace`的`loc`，不使用系统语言或时区。国家表示访问网络出口，不宣称居住地。地区仅决定展示，不赋予账号、订单或购买资格。

两档价及功能状态依旧由生产目录生成，初始价格节点均隐藏；脚本按语言／地区确认后只显示一档，避免先闪现另一币种。非中文界面地区缺失、非法、请求失败或超时均明确提示无法读取价格，用户可重试；不显示猜测价、不默认特价，不轮询、不落盘缓存、不保存或记录trace／IP。价格展示需要脚本；无脚本仍能阅读权益及交易说明，并提示启用JavaScript。此范围取代上节旧版双价全静态展示。Cloudflare端点说明：https://developers.cloudflare.com/fundamentals/reference/cdn-cgi-endpoint/ 。

页面沿用实际付款页的MiSans、品牌色、轻玻璃轮廓与24px圆角，按产品内PlanComparison的免费／Pro卡片列功能与状态，删除原整张表格和移动端逐行Free/Pro重复标签。计划中项以App同样的灰色文字、功能图标和轮廓胶囊标签呈现。导航、语言菜单与页脚保持；2026-11-05移除退款区块后，计费说明使用单列，不留下原双列空位。官网未创建付款按钮，用户前往桌面应用购买。字体子集与许可证、重生成入口见`resource/fonts/README.md`。

## App与官网共用套餐呈现（2026-11-05）

- 价格、中文方案文案、功能顺序、图标语义ID及状态继续读取API同一公开目录；官网不改写中文功能名。
- `../desktop/src/shared/pro-plan-copy.json`拥有套餐翻译及状态用语。App中英文目录直接引用；官网不再保留独立功能词条。日／西语按同一语义ID在该静态资源集中维护，不新增App语言入口。
- App `product/v1.tsx`的`PLAN_ICONS`及可用Check定义拥有SVG，`node devtools/export-pro-plan-presentation.mjs`导出`resource/pro-plan-presentation.json`。`--check`验证资源与App同步，`build:hero`亦同步导出。普通官网生成与部署只读取已提交的资源，不要求生产访问Desktop文件。
- 中文使用“计划中”，对应截图中的App状态，替代本轮早先临时的“草拟／拟”。官网不显示账号相关的“当前”标识。
- 早鸟价移到金额／年费右侧，使用轻描边胶囊标签；金额与早鸟资格仍从公共目录派生。窄屏允许价格行自然换行。
- 修改共享翻译后先导出，再`npm run build:i18n`；新增字形后再按字体README生成子集。金额、付款与App发布流程保持原归属。
