はい。対象の会話を開くと保存が始まります。Gemini では読み込み方式の都合上、20 件以上のメッセージがある会話は過去のメッセージを手動で読み込む必要があります。

Chat Memo は現在、ChatGPT、Gemini、Claude、DeepSeek、Google AI Mode、Doubao、Kimi、Qwen、Tencent Yuanbao の Web 版の会話に対応しています。
スマートフォンアプリ、デスクトップアプリ、コーディングツール内の会話は自動保存できません。
ご要望は フィードバックからお寄せください。

Web ページと拡張機能の連携がうまく始まらなかった可能性があります。まずページを再読み込みしてください。解決しない場合は、フィードバックからご連絡ください。

お使いのブラウザでサイドバーが開かない場合は、最新版の Chrome または Edge でお試しください。それでも解決しない場合は、調査のためブラウザ名とバージョンをお知らせください。

保存状態をわかりやすく示すため、目立つデザインにしています。気になる場合は、ラベルをドラッグして好きな位置へ移動できます。

Chat Memo が対応するサービスの会話なら、まず Chat Memo 内の該当記録を削除し、元のページを再読み込みして取り込み直してください。
古いメッセージを読み込む際は、各回の読み込みが終わるのを待ちながら一定の速さでスクロールしてください。素早いスクロールや連続した読み込みは避けてください。
それでも欠ける場合は、フィードバックからご連絡ください。

Chat Memo は現在、会話に追加されたメッセージや既存メッセージの明確な変更を同期します。
Web ページによって内容の読み込み方や識別方法が異なるため、既存メッセージを直接削除しても、Chat Memo 側では自動削除しません。誤って保存済みの内容が消えることを防ぐためです。
両方の内容を一致させたい場合は、Chat Memo で会話全体の記録を削除し、元のページから取り込み直してください。個別メッセージの削除は今後のバージョンで対応予定です。
